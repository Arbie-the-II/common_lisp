# ☕ Building a Touchscreen POS Terminal in Common Lisp

This guide provides a complete, step-by-step walkthrough for building a fully responsive, event-driven **Point of Sale (POS) mockup application** using Common Lisp and the **LTK** (Lisp Toolkit) interface library.

---

## 🛠️ Step 1: Initialize the Project Workspace

Before writing any code, create a dedicated folder structure on your Windows machine to isolate your source scripts and graphic assets.

1. Create a directory at `C:\Users\user\Documents\lisp\`.
2. Inside this folder, place your item image files (saved in `.gif` format):
   * `logo.gif` (Main store header banner)
   * `espresso.gif`, `caffe_latte.gif`, `croissant.gif`, `muffin.gif`, `green_tea.gif`, `iced_coffee.gif` (Button tile icons)

---

## 📦 Step 2: Establish the Compilation Script (`build.lisp`)

To compile the application into a standalone Windows executable safely without crashing or throwing thread-management errors, create a file named `build.lisp` in your project folder and add this stable compilation routine:

```lisp
;; 1. Manually boot Quicklisp since we are bypassing the auto-init file
(let ((quicklisp-init (merge-pathnames "quicklisp/setup.lisp" (user-homedir-pathname))))
  (when (probe-file quicklisp-init)
    (load quicklisp-init)))

;; 2. Load your app code blocks
(load "app.lisp")

(in-package :cl-user)

;; 3. Terminate background helper threads before freezing memory core
(dolist (thread (sb-thread:list-all-threads))
  (unless (eq thread sb-thread:*current-thread*)
    (ignore-errors (sb-thread:terminate-thread thread))))

;; 4. Save the executable image cleanly WITHOUT compression using a console stream
(sb-ext:save-lisp-and-die "my-gui-app.exe" 
                          :toplevel #'my-gui-app:start-app 
                          :executable t 
                          :compression nil
                          :application-type :console)

```

## 💻 Step 3: Develop the Application Core (`app.lisp`)

Create a file named `app.lisp` in your workspace. The program is broken down into four foundational blocks:

### 1. Package Definition & State Initialization

We load Quicklisp dependencies, declare an isolated application package environment, and establish our menu database paired with global order state lists.

```lisp
(ql:quickload :ltk)

(defpackage :my-gui-app
  (:use :cl :ltk)
  (:export :start-app))

(in-package :my-gui-app)

;; --- RETAIL INVENTORY DATA ---
(defparameter *inventory* '(("Espresso" 3.50 "espresso.gif")
                            ("Caffe Latte" 4.25 "caffe_latte.gif")
                            ("Croissant" 3.75 "croissant.gif")
                            ("Muffin" 3.50 "muffin.gif")
                            ("Green Tea" 3.00 "green_tea.gif")
                            ("Iced Coffee" 4.00 "iced_coffee.gif")))

;; --- SYSTEM STATE VARIABLES ---
(defparameter *tax-rate* 0.08)
(defparameter *cart* nil)
(defparameter *subtotal* 0.0)

```

### 2. Business Logic Calculations

This functional segment tracks state updates by aggregating prices via `reduce` and returning the transaction totals using multiple values.

```lisp
(defun update-totals ()
  (setf *subtotal* (reduce #'+ (mapcar #'cdr *cart*)))
  (let* ((tax (* *subtotal* *tax-rate*))
         (total (+ *subtotal* tax)))
    (values *subtotal* tax total)))

```

### 3. Creating the Layout Hierarchy

Inside the main execution environment `(with-ltk ())`, we construct structural frames and organize them across coordinate grids using weights to make the final application responsive.

```lisp
(defun start-app ()
  (with-ltk ()
    (wm-title *tk* "Lisp Graphic POS Terminal")
    (setf (geometry *tk*) "900x650")
    
    (on-close *tk* (lambda () 
                     (setf *cart* nil)
                     (exit-wish)))

    (grid-columnconfigure *tk* 0 :weight 1)
    (grid-rowconfigure *tk* 2 :weight 1)

    ;; --- MAIN LOGO BANNER SETUP ---
    (let* ((app-dir (or (uiop:pathname-directory-pathname (uiop:argv0))
                        *default-pathname-defaults*))
           (header-frame (make-instance 'frame :master *tk*))
           (logo-label (make-instance 'label :master header-frame))
           (header-text (make-instance 'label :master header-frame :text "LISP POS SYSTEM" :font "Arial 14 bold")))
      
      (let ((main-logo-path (namestring (merge-pathnames "logo.gif" app-dir))))
        (when (probe-file main-logo-path)
          (let ((img (make-image)))
            (image-load img main-logo-path)
            (configure logo-label :image img)
            (pack logo-label :side :left :padx 10))))

      (pack header-text :side :left :padx 5)
      (grid header-frame 0 0 :pady 10)

      ;; --- SPLIT WINDOW PANELS ---
      (let* ((content-frame (make-instance 'frame :master *tk*))
             (menu-frame (make-instance 'labelframe :master content-frame :text " Quick-Select Menu Tiles "))
             (receipt-frame (make-instance 'labelframe :master content-frame :text " Current Order Receipt "))
             
             (cart-listbox (make-instance 'listbox :master receipt-frame :width 35))
             (lbl-subtotal (make-instance 'label :master receipt-frame :text "Subtotal: $0.00" :font "Arial 10"))
             (lbl-tax (make-instance 'label :master receipt-frame :text "Tax (8%): $0.00" :font "Arial 10"))
             (lbl-total (make-instance 'label :master receipt-frame :text "Total: $0.00" :font "Arial 12 bold"))
             
             (btn-clear (make-instance 'button :master receipt-frame :text "Clear Order"))
             (btn-checkout (make-instance 'button :master receipt-frame :text "💳 Process Payment")))

        (grid content-frame 2 0 :sticky "nesw" :padx 10 :pady 5)
        (grid-columnconfigure content-frame 0 :weight 3)
        (grid-columnconfigure content-frame 1 :weight 2)
        (grid-rowconfigure content-frame 0 :weight 1)

        (grid menu-frame 0 0 :sticky "nesw" :padx 5 :pady 5)
        (grid receipt-frame 0 1 :sticky "nesw" :padx 5 :pady 5)

        (grid-columnconfigure menu-frame 0 :weight 1)
        (grid-columnconfigure menu-frame 1 :weight 1)

```

### 4. Grid Generation & Dynamic Event Mapping

The application loops over the inventory array to generate grid selections. To prevent image sizing errors, it automatically downsamples larger graphics by a factor of four using Tcl/Tk's internal canvas subsystem.

```lisp
        ;; --- BOX TILE GRID GENERATION WITH AUTOMATIC SCALING ---
        (let ((row 0)
              (col 0))
          (dolist (item *inventory*)
            (let* ((item-name (first item))
                   (item-price (second item))
                   (item-img-file (third item))
                   (btn-text (format nil "~A~%~%$~,2F" item-name item-price))
                   (item-btn (make-instance 'button :master menu-frame :text btn-text)))
              
              (grid-rowconfigure menu-frame row :weight 1)
              (grid item-btn row col :sticky "nesw" :padx 8 :pady 8 :ipadx 10 :ipady 10)
              
              (let ((full-img-path (namestring (merge-pathnames item-img-file app-dir))))
                (when (probe-file full-img-path)
                  (let ((raw-img (make-image))
                        (scaled-img (make-image)))
                    (image-load raw-img full-img-path)
                    (send-wish (format nil "~A copy ~A -subsample 4 4" 
                                       (ltk::name scaled-img) 
                                       (ltk::name raw-img)))
                    (configure item-btn :image scaled-img :compound "top"))))

              ;; Tile Click Callback Action
              (setf (command item-btn)
                    (lambda ()
                      (push (cons item-name item-price) *cart*)
                      (listbox-append cart-listbox (format nil "  ~A (~,2F)" item-name item-price))
                      (multiple-value-bind (sub tax tot) (update-totals)
                        (setf (text lbl-subtotal) (format nil "Subtotal: $~,2F" sub)
                              (text lbl-tax) (format nil "Tax (8%): $~,2F" tax)
                              (text lbl-total) (format nil "Total: $~,2F" tot)))))

              (if (= col 0)
                  (setf col 1)
                  (progn (setf col 0)
                         (incf row))))))

        ;; --- RIGHT SIDE RECEIPT PANEL ---
        (grid-columnconfigure receipt-frame 0 :weight 1)
        (grid-columnconfigure receipt-frame 1 :weight 1)
        (grid-rowconfigure receipt-frame 0 :weight 1)

        (grid cart-listbox 0 0 :columnspan 2 :sticky "nesw" :padx 5 :pady 5)
        (grid lbl-subtotal 1 0 :columnspan 2 :sticky "e" :padx 10 :pady 2)
        (grid lbl-tax 2 0 :columnspan 2 :sticky "e" :padx 10 :pady 2)
        (grid lbl-total 3 0 :columnspan 2 :sticky "e" :padx 10 :pady 4)
        
        (grid btn-clear 4 0 :sticky "ew" :padx 5 :pady 10)
        (grid btn-checkout 4 1 :sticky "ew" :padx 5 :pady 10)

        ;; --- SYSTEM CALLBACKS ---
        (setf (command btn-clear)
              (lambda ()
                (setf *cart* nil)
                (listbox-clear cart-listbox)
                (setf (text lbl-subtotal) "Subtotal: $0.00"
                      (text lbl-tax) "Tax (8%): $0.00"
                      (text lbl-total) "Total: $0.00")))

        (setf (command btn-checkout)
              (lambda ()
                (when *cart*
                  (multiple-value-bind (sub tax tot) (update-totals)
                    (declare (ignore sub tax))
                    (do-msg (format nil "Transaction Approved!~%Processed Final Bill total: $~,2F" tot)
                            :title "POS Success")
                    (setf *cart* nil)
                    (listbox-clear cart-listbox)
                    (setf (text lbl-subtotal) "Subtotal: $0.00"
                          (text lbl-tax) "Tax (8%): $0.00"
                          (text lbl-total) "Total: $0.00")))))))))

```

## 🚀 Step 4: Compilation and Deployment


### Option 1
## 🖥️ Method 1: 

### Run & Compile in One Step Using Windows Command Prompt (CLI)

Open your Command Prompt (`cmd.exe`), navigate (`cd`) to your project directory containing `app.lisp`, and execute:

```cmd
sbcl --load app.lisp --eval "(my-gui-app::start-app)"

```

> **Note:** The double-colon `::` explicitly tells SBCL to access the internal `start-app` function within the `my-gui-app` package namespace.

### How to Exit

* **From the Application GUI:** Simply click the native **`X`** close button in the top right corner of the window.
* **From a running REPL Prompt (`*`):** ```lisp
(sb-ext:exit)
```
```
* **From an Error Debugger Prompt (`0]`):** Type the target exit/abort option number (typically `4` or higher depending on the stack) and press **Enter**.

### Option 2
## 🖥️ Method 2: 
With your assets and source files stored together inside your working directory, complete your deployment using the Windows PowerShell command line.

### 1. Close Background Tasks

Before recompiling, make sure to drop any active system holds on your target executable so Windows doesn't block the compilation step:

```powershell
Stop-Process -Name "my-gui-app" -Force -ErrorAction SilentlyContinue

```

### 2. Run the Compiler Core Using Windows Command Prompt (CLI)

Invoke Steel Bank Common Lisp (SBCL) with the `--no-userinit` safety flag to load your custom script cleanly:

```powershell
sbcl --no-userinit --load build.lisp

```

### 3. Launching the App Seamlessly

Because we selected `:application-type :console`, clicking `my-gui-app.exe` directly would normally open a blank black terminal window right behind your beautiful POS system.

1. To hide that terminal window and make it look like a seamless corporate application for your presentation, use a simple Visual Basic launcher script (`launch.vbs`) placed right next to your `.exe`:

```vbs
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "my-gui-app.exe", 0, False

```

Double-click **`launch.vbs`** to open your complete, image-backed, fully responsive Lisp Point of Sale terminal!
2. or just simply type `.\my-gui-app or .\launch` on your terminal
